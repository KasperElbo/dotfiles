# Neovim configuration

This is this repository's own [LazyVim](https://github.com/LazyVim/LazyVim)
configuration, not the vanilla starter template. It began from the
[LazyVim/starter](https://github.com/LazyVim/starter) template — the retained
`LICENSE` in this directory reflects that origin — and has since been
customized: plugin choices, keymaps, and options here are specific to this
dotfiles repository and its supported platforms.

For how this configuration is installed, kept in sync, and used day to day,
see [`docs/workflows/editor.md`](../../../docs/workflows/editor.md). For what
is vendored or derived from upstream here, and under which licence, see
[`docs/reference/third-party-notices.md`](../../../docs/reference/third-party-notices.md).
