\cssection{Ghostty}
\csnote{No \texttt{keybind =} is set anywhere in this config --- every shortcut is an unmodified upstream default (varies by platform/version).}
Ghostty owns tabs/splits/zoom locally; tmux does not duplicate this. Copy/paste use the platform's normal clipboard shortcut (\texttt{Ctrl+Shift+C/V} on Linux/Wayland, \texttt{Cmd+C/V} on macOS).\par
\cslegend{\texttt{ghostty +list-keybinds --default} $\to$ exact tab/split/zoom/reload keys.}

\cssection{Shell (Zsh)}
